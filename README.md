# HVMC School Launcher

HVMC School Launcher is the custom Windows launcher for Hero's Vault MC, designed for school and care-organisation PCs.

## Windows app

The user-facing application is named **HVMC School Launcher**. The first time `HVMCLauncher.exe` is opened, it installs itself into:

```text
%LOCALAPPDATA%\Bendemen\HVMC\App\HVMCLauncher.exe
```

It then creates:

- a **HVMC School Launcher** entry in the Windows Start Menu;
- a **HVMC School Launcher** shortcut on the desktop;
- a per-user uninstall entry under Windows Installed Apps / Programs.

After the first launch, users open the launcher from Windows like a normal installed application. Administrator rights are not required for the per-user installation.

## Launcher interface

The launcher keeps the user-facing flow intentionally simple:

- **SPELEN**
- **AFSLUITEN**

On first use a PC must be authorised once with a code generated by the HVMC admin dashboard. After authorisation, no youth login and no separate Provisioner application are required.

## PC authorisation

1. Open the HVMC admin dashboard.
2. Open **PC Beheer**.
3. Generate a one-time PC code.
4. Start HVMC School Launcher on the school PC.
5. Enter the 10-character code.
6. The PC receives a device token and becomes associated with that installation until an administrator removes or re-authorises it.

The code expires after 15 minutes and can only be used once.

The launcher stores only its own PC identity and device token locally. Microsoft passwords and Microsoft refresh tokens are never stored on the school PC.

## PC management dashboard

The admin dashboard provides:

- one-time PC authorisation codes;
- PC name management;
- online/offline status;
- launcher and Windows version information;
- organisation assignment;
- block/unblock;
- PC removal;
- current Minecraft account/lease visibility.

PC heartbeats are sent periodically. Blocking a PC immediately releases its active account lease.

## Microsoft account pool

Microsoft pool accounts are managed centrally from the admin dashboard at `accounts.hvmc.nl`.

Administrators can link or relink Microsoft accounts through the dashboard. The server stores the Microsoft refresh token encrypted with AES-256-GCM. The launcher receives only the temporary Minecraft session required to start the game.

There is intentionally **no Provisioner.exe**. Microsoft account management belongs on the protected admin dashboard, not on school PCs.

## Minecraft and Fabric

HVMC targets:

- Minecraft Java Edition **1.21.11**
- Fabric Loader **0.18.1**
- Windows x64

The launcher prepares Minecraft and Fabric automatically and starts Minecraft fullscreen using the detected primary display resolution. Fabric is installed with the official Windows installer when the required Fabric profile is missing. ## Content synchronisation

Managed Minecraft content is stored under `content/` in the repository:

```text
content/
├─ mods/
├─ config/
├─ resourcepacks/
├─ shaderpacks/
├─ datapacks/
└─ kubejs/
```

`HVMCUpdater.ps1` performs an incremental synchronisation:

- unchanged files are kept;
- changed files are replaced after Git blob SHA verification;
- new files are downloaded;
- files removed from the managed repository are removed locally;
- required Minecraft directories are created automatically;
- Fabric is installed when missing.

The updater also keeps a local manifest and state file under `%LOCALAPPDATA%\Bendemen\HVMC`.

The launcher downloads the current updater script before running it. The updater runs without opening a visible command prompt.

## Launcher updates

HVMC School Launcher checks the latest stable GitHub release at startup. When a newer `HVMCLauncher.exe` is available, the installed launcher downloads the new binary, verifies that it differs from the current executable, replaces itself after exiting and starts the new version.

Because the application lives in the stable per-user application directory, Start Menu and desktop shortcuts continue to point to the updated executable.

## Offline behaviour

Managed Minecraft content is kept locally, so an existing installation can continue to use its local content when the content endpoint is temporarily unavailable.

Account leasing and PC authorisation require `accounts.hvmc.nl`; when the account service is unavailable, the launcher will not claim a new account lease.

## Releases and versioning

HVMC uses simple user-facing release versions:

- first stable release: **HVMC Release v1.0**
- small updates: **v1.1**, **v1.2**, **v1.3**, ...
- major updates: **v2.0**, **v3.0**, ...
- maintenance releases can continue as **v2.1**, **v2.2**, etc.

`version.txt` is the content version source of truth. Public launcher releases are created only from version tags such as `v1.0`, `v1.1`, or `v2.0`; normal commits do not create public releases.

## Security

Never commit any of the following to GitHub:

- Microsoft passwords;
- Microsoft refresh tokens;
- admin passwords;
- `POOL_ENCRYPTION_KEY`;
- `ADMIN_TOKEN`;
- other production secrets.

Production secrets belong in the VPS environment configuration.

## Server

The account-pool API runs behind Caddy at `accounts.hvmc.nl` and listens locally on `127.0.0.1:8080`.

The service provides:

- administrator authentication;
- Microsoft device linking;
- encrypted account-pool credentials;
- automatic account leasing;
- PC authorisation and management;
- lease heartbeat/release handling.

After server source changes, deploy the `server/` application to the VPS and restart `hvmc-account-pool.service`.
