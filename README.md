# HVMC School Launcher

HVMC is the school Minecraft launcher and account-pool client.

### About the Launcher

The **HVMC Launcher** is a dedicated Minecraft launcher designed for **schools, care organizations, youth organizations, and other organizations that need to provide Minecraft access across a large number of PCs**.

Instead of requiring every computer to be configured manually with separate Minecraft accounts and installations, the HVMC Launcher provides a centralized and controlled solution. This makes it easier for organizations to manage Minecraft access across classrooms, activity rooms, gaming spaces, and shared computers.

## Built for Organizations

The launcher is designed with environments in mind where many different users may use the same computers. Organizations can manage a pool of Minecraft accounts and allow authorized PCs to temporarily use an available account when Minecraft is started.

This makes the HVMC Launcher particularly suitable for:

- Schools and educational institutions
- Care and youth organizations
- Community and activity centers
- Gaming and esports facilities
- Other organizations managing multiple shared PCs

## Kid-Proof by Design

The HVMC Launcher is designed to be **kid-proof** and simple to use.

The goal is to minimize the number of things a child or end user needs to configure themselves. Account management, authentication, and technical configuration are handled by the launcher and the organization's account infrastructure.

This helps prevent accidental configuration changes and makes the launcher suitable for environments where children or other non-technical users operate the PCs.

## Automatic Updates

The HVMC Launcher is built to **update itself automatically**.

When a new launcher version is released, the launcher can detect the update and install it without requiring administrators to manually update every individual computer.

This allows organizations to keep large numbers of PCs up to date while significantly reducing maintenance work for IT staff and administrators.

## Centralized Account Management

The HVMC ecosystem can provide a centralized Minecraft account pool for organizations.

Instead of permanently assigning a Minecraft account to every individual PC, accounts can be temporarily assigned to authorized computers when needed. Once the session is finished, the account can be released and made available to another authorized PC.

This makes it possible to use a smaller pool of Minecraft accounts across a larger number of shared computers.

## Designed for Shared Computers

The HVMC Launcher is especially useful for environments where PCs are shared between many users.

A typical setup can look like:

**Organization → Account Pool → Authorized PCs → Users**

The organization controls the available accounts and authorized computers, while the launcher handles the technical process of obtaining and releasing an account when Minecraft is used.

The result is a simpler and more manageable Minecraft experience for organizations operating multiple PCs.
