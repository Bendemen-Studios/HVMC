# Hero's Vault MC Launcher

HVMC is the custom Windows launcher for Hero's Vault MC, designed for school and care-organisation PCs.

## Windows app

The user-facing HVMC launcher is a normal per-user Windows app. The first time `HVMCLauncher.exe` is opened, it installs itself into:

```text
%LOCALAPPDATA%\Bendemen\HVMC\App\HVMCLauncher.exe
```

It then creates:

- a **HVMC** entry in the Windows Start Menu;
- a **HVMC** shortcut on the desktop.

After the first launch, users open HVMC from the Start Menu or desktop like a normal app. They do not need to keep opening a downloaded `.exe` file manually.

HVMC does not require administrator rights for this per-user installation.

## Launcher interface

The launcher provides a deliberately simple interface:

- **SPELEN**
- **AFSLUITEN**

On first use a PC must be authorised once with a code generated by the HVMC admin dashboard. After authorisation, no youth login and no Provisioner application are required.

## PC authorisation

1. Open the HVMC admin dashboard.
2. Open **PC Beheer**.
3. Generate a one-time PC code.
4. Start HVMC on the school PC.
5. Enter the 10-character code.
6. The PC receives a device token and is permanently associated with that installation until an administrator removes or re-authorises it.

The code expires after 15 minutes and can only be used once.

The launcher stores only its own PC identity and device token locally. Microsoft passwords and Microsoft refresh tokens are never stored on the youth PC.

## PC management dashboard

The admin dashboard provides:

- one-time PC authorisation codes;
- PC name management;
- online/offline status;
- launcher and Windows version information;
- organisation assignment;
- block/unblock;
- PC removal;
- current Minecraft account/lease visibility.

PC heartbeats are sent periodically. Blocking a PC immediately releases its active account lease.

## Microsoft account pool

Microsoft pool accounts are managed centrally from the admin dashboard at `accounts.hvmc.nl`.

Administrators can link or relink Microsoft accounts through the dashboard. The server stores the Microsoft refresh token encrypted with AES-256-GCM. The launcher receives only the temporary Minecraft session required to start the game.

There is intentionally **no Provisioner.exe**. Microsoft account management belongs on the protected admin dashboard, not on youth PCs.

## Minecraft and Fabric

HVMC targets:

- Minecraft Java Edition **1.21.11**
- Fabric Loader **0.18.1**
- Windows x64

The launcher prepares Minecraft and Fabric automatically and starts Minecraft fullscreen using the detected primary display resolution.

## Content synchronisation

Managed Minecraft content is stored under `content/` in the repository:

```text
content/
├─ mods/
├─ config/
├─ resourcepacks/
├─ shaderpacks/
├─ datapacks/
└─ kubejs/
```

`HVMCUpdater.ps1` performs an incremental synchronisation:

- unchanged files are kept;
- changed files are replaced after Git blob SHA verification;
- new files are downloaded;
- files removed from the managed repository are removed locally;
- required Minecraft directories are created automatically;
- Fabric is installed when missing.

The updater also keeps a local manifest and state file under `%LOCALAPPDATA%\Bendemen\HVMC`.

The launcher downloads the current updater script before running it. The updater is executed without opening a visible command prompt.

## Launcher updates

HVMC checks the latest stable GitHub release at startup. When a newer `HVMCLauncher.exe` is available, the installed launcher downloads the new binary and replaces itself after exiting.

Because the real application lives in the stable per-user application directory, updates also update the executable used by the Start Menu and desktop shortcuts.

## Offline behaviour

Managed Minecraft content is already kept locally, so an existing installation can continue to use its local files when the content endpoint is temporarily unavailable.

Account leasing and PC authorisation require `accounts.hvmc.nl`; when the account service is unavailable, HVMC will not claim a new account lease.

## Releases and versioning

HVMC uses simple user-facing release versions:

- first stable release: **HVMC Release v1.0**
- small updates: **v1.1**, **v1.2**, **v1.3**, ...
- major updates: **v2.0**, **v3.0**, ...
- maintenance releases can continue as **v2.1**, **v2.2**, etc.

`version.txt` remains the content version source of truth. GitHub releases are created only from version tags such as `v1.0`, `v1.1`, or `v2.0`; normal commits do not create public releases.

## Security

Never commit any of the following to GitHub:

- Microsoft passwords;
- Microsoft refresh tokens;
- admin passwords;
- `POOL_ENCRYPTION_KEY`;
- `ADMIN_TOKEN`;
- other production secrets.

Production secrets belong in the VPS environment configuration.

## Server

The account-pool API runs behind Caddy at `accounts.hvmc.nl` and listens locally on `127.0.0.1:8080`.

The service provides:

- administrator authentication;
- Microsoft device linking;
- encrypted account-pool credentials;
- automatic account leasing;
- PC authorisation and management;
- lease heartbeat/release handling.

After server source changes, deploy the `server/` application to the VPS and restart `hvmc-account-pool.service`.
